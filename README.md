# Herramientas de soporte CONTPAQi (Dattasoft)

Repositorio de **solo descargas**: aquí se publican como Releases los ejecutables
(.exe para Windows) de las herramientas internas que usa el equipo de soporte de
Dattasoft en equipos de clientes. No contiene el código fuente de las herramientas.

Uso interno — generadas por el equipo de soporte, sin garantía. Requieren Windows y,
en la mayoría de los casos, ejecutarse como administrador.

Se descargan normalmente desde la pestaña **🛠️ Herramientas** del
[Asistente de Soporte CONTPAQi](https://asistente-soporte-contpaqi.streamlit.app/).

## Herramientas disponibles

| Herramienta | Para qué sirve |
|---|---|
| [Ejecutor Desinstalador CONTPAQi](../../releases/tag/desinstalador) | Desinstala sistemas CONTPAQi (con modo de prueba y respaldo previo) y lee números de serie (AppKey) registrados en el equipo. |
| [Configurador de Red Remoto Pro](../../releases/tag/ip) | Configura y diagnostica la red de un equipo remoto/cliente (IP, avisos por correo, vigilante de red). |
| [Panel Migración CONTPAQi](../../releases/tag/migracion-sql) | Respalda/restaura instancias de SQL Server y adjunta bases de datos masivamente por línea de negocio al migrar de servidor. |
| [Panel PRE/POST Instalación CONTPAQi](../../releases/tag/pre-post-instalacion) | Prepara un equipo antes/después de instalar CONTPAQi: características de Windows, permisos de registro, firewall, exclusiones de Defender, idioma/región. |
