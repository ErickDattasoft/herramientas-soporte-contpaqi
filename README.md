# Herramientas de soporte CONTPAQi (Dattasoft)

Repositorio de **solo descargas**: aquí se publican como Releases los ejecutables
(.exe para Windows) de las herramientas internas que usa el equipo de soporte de
Dattasoft en equipos de clientes. No contiene el código fuente de las herramientas.

Uso interno — generadas por el equipo de soporte, sin garantía. Requieren Windows y,
en la mayoría de los casos, ejecutarse como administrador.

Se descargan normalmente desde la pestaña **🛠️ Herramientas** del
[Asistente de Soporte CONTPAQi](https://asistente-soporte-contpaqi.streamlit.app/).

## Herramientas disponibles

| Herramienta | Para qué sirve |
|---|---|
| [PROYECTO Desinstalador](../../releases/tag/desinstalador) | Desinstala sistemas CONTPAQi con modo de prueba (dry-run) activado por defecto y confirmación explícita antes de correr en modo real; respalda antes de borrar. Incluye un lector de AppKey/números de serie registrados en el equipo, con filtro por sistema y botón para copiar la serie — útil cuando el buscador de "Licencias" no encuentra la empresa. |
| [PANEL IP](../../releases/tag/ip) | Configura y diagnostica la red de un equipo remoto/cliente: reclamar IP, revisar y confirmar cambios de red, configurar avisos por correo, y vigilante de red. |
| [PANEL MIGRACION](../../releases/tag/migracion-sql) | Automatiza la migración de bases de datos SQL Server entre servidor origen y destino: respaldo/restauración de instancias DATA y adjuntado masivo de bases por línea de negocio (Contabilidad, Nóminas, Comercial Premium, ADD). |
| [PANEL PRE POST INSTALACION](../../releases/tag/pre-post-instalacion) | Automatiza la preparación de un equipo antes/después de instalar CONTPAQi: habilita características de Windows necesarias, ajusta permisos de registro y carpetas, abre puertos de firewall por línea de negocio, agrega exclusiones a Windows Defender, y configura idioma/región del sistema. |
